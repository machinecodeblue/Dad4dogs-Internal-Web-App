# Decisions

Archive of proposals that have already been **accepted, rejected, or partly applied**.

This folder is a historical record. It is **not** the live spec. Do not implement from here, and do not edit these files to change how the app works — update the domain file named in the Decision header (`platform.md`, `customers.md`, …).

Each file is the original proposal text, moved from `LLM/Proposed work/`, with a **Decision** block at the top:

- **Status:** accepted / rejected / partial
- **Live spec:** where standing rules live now (or “none” if rejected)
- **What we took / left:** short summary
- **Why:** one or two sentences

Open proposals stay in `Proposed work/` until David decides.
